# 📊 Executive Retail Sales Dashboard (Excel)

## 📌 Project Overview
An interactive retail sales dashboard built in Microsoft Excel using 51k+ transactional records. The goal of this project is to analyze total revenue, profitability, regional distributions, and product category performance to drive data-informed commercial decisions.

![Sales Dashboard](dashboard.png)

---

## 🛠️ Key Features & Technical Implementation
- **Data Cleaning & Modeling**: Cleaned missing values and prepared datasets using standard Excel formulas and Pivot Tables.
- **KPI Metrics**: Calculated **Total Revenue**, **Total Profit**, **Average Order Value (AOV)**, and **Total Orders**.
- **Interactive UI/UX**: Designed a clean layout with gridlines removed, custom visual hierarchy, and cross-filtered **Slicers** connected across all Pivot Tables and Charts.

---

## 📊 Business Insights & Key Findings

### Executive Summary
Over the analyzed period, the business generated **$12.64M in Total Revenue** and **$1.47M in Total Profit** across **51,290 orders**, with an **Average Order Value (AOV) of $246**.

### Key Findings
* **Top Performing Category**: **Technology** leads total sales with **$4.74M**, closely followed by **Furniture ($4.11M)** and **Office Supplies ($3.79M)**.
* **Regional Dominance**: The **Central** region is the top-performing territory, generating **$2.82M** (~22.3% of global revenue).
